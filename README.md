# 🤖 SwiftDataAnalyst-Agent

An autonomous data analytics agent powered by **SwiftSci** combining sandboxed dynamic tool execution, RAG context synthesis, and native wire protocol database drivers.

## 🌟 Highlights
- **Sandboxed Tool AST Evaluator**: Dynamic, injection-safe execution of data transformation pipelines via `SwiftAgentEvaluator`.
- **RAG Context Generator**: Token-efficient schema profiling for local and remote LLM agents (`SwiftAgent`).
- **High-Performance In-Memory Analytics**: Columnar vectorized query engine (`SwiftDataFrame`).
- **Native SQL Connectivity**: Pure-Swift PostgreSQL and MySQL wire-protocol clients (`SwiftDatabase`).

## 🚀 Running the Project

```bash
swift run SwiftDataAnalyst
```

### Running Tests
```bash
swift test
```
